# Фиксированный тестовый набор промптов

Используется для честного сравнения моделей: прогоняется без изменений через
каждую интегрированную модель (LTX 2.3 Director, MiniMax H3, позже — Wan 2.2).
Результаты — в /metrics сервиса (тайминги) + ручная оценка по рубрике из отчёта, раздел 13.3.

Как использовать:
1. Прогнать каждый промпт через каждую модель на дефолтных настройках разрешения.
2. Записать: время генерации (из /metrics), успех/ошибка, оценку 1-5 по пунктам рубрики.
3. Для LTX — отдельно промпты 11-12 идут как список СЦЕН (несколько промптов на одну
   генерацию), а не один текст — см. пометку.

---

## Категория A: статичная сцена (без активного движения камеры/объектов)

1. Пустая комната с большим окном, мягкий дневной свет, пылинки в воздухе, минимализм в интерьере.
2. Чашка кофе на деревянном столе у окна, пар поднимается вверх, размытый городской пейзаж на фоне.

## Категория B: динамика и движение камеры

3. Камера облетает вокруг горного пика на рассвете, облака проплывают внизу, драматичное освещение.
4. Быстрая проездка камеры вдоль неоновой улицы ночного мегаполиса под дождём, отражения в лужах.
5. Плавный наезд камеры на лицо человека, сидящего у костра ночью, отблески пламени на коже.

## Категория C: несколько персонажей в кадре

6. Два человека разговаривают за столиком уличного кафе, оживлённая улица на фоне, естественные жесты.
7. Группа людей идёт по коридору офиса, деловая атмосфера, дневной свет из окон.

## Категория D: разный визуальный стиль

8. Реалистичное документальное видео: рыбак чинит сеть на пристани, раннее утро, туман над водой.
9. Мультипликационная сцена в стиле 2D-анимации: лиса бежит по осеннему лесу, яркие тёплые тона.
10. Кинематографичный нуар: детектив в плаще под уличным фонарём, чёрно-белая гамма с одним ярким акцентным цветом.

## Категория E: короткие/длинные ролики (специфично для LTX — список сцен)

11. Список сцен (одна генерация LTX Director, ~15 сек суммарно):
    - Сцена 1 (5 сек): человек входит в старую библиотеку, пыльные полки книг до потолка.
    - Сцена 2 (5 сек): крупный план — рука проводит по корешкам книг, выбирает одну.
    - Сцена 3 (5 сек): человек садится в кресло у камина, открывает книгу, огонь потрескивает.

12. Список сцен (одна генерация LTX Director, ~45 сек суммарно — проверка "почти предельной" длины):
    - Сцена 1 (10 сек): восход над океаном, волны разбиваются о скалы.
    - Сцена 2 (10 сек): чайки кружат над водой, крики птиц.
    - Сцена 3 (10 сек): маяк на утёсе, свет вращается в сумерках.
    - Сцена 4 (15 сек): рыбацкая лодка возвращается в порт на закате.

## Категория F: звук как часть сцены (важно для LTX/MiniMax — оба генерируют звук нативно)

13. Кузница: кузнец бьёт молотом по раскалённому металлу, искры разлетаются, характерный звон металла.
14. Гроза: молния освещает поле, раскаты грома, шум ливня по крыше сарая.

## Категория G: короткий шот на пределе минимальной длительности (проверка нижней границы)

15. Один прыжок баскетболиста к кольцу, мяч влетает в сетку, короткий динамичный момент.
    (Прогнать на 1 сек / 2 сек / 4 сек — сравнить, с какой длительности результат
    перестаёт быть "обрубленным на середине действия".)

---

## Общие замечания к прогону

- Prompt для "общего стиля" (global_prompt) в LTX для промптов 1-10 — оставить пустым,
  чтобы не искажать сравнение между моделями лишним контекстом.
- Seed — либо фиксировать один и тот же для всех моделей (для чистоты сравнения
  детерминизма), либо явно рандомизировать и повторить 2-3 раза на промпт для оценки
  разброса качества между сидами. Параметр seed уже поддержан в build_workflow() у обеих моделей.
- Разрешение — прогнать сначала на дефолтных настройках (авто у LTX / 0.4 МП у MiniMax),
  отдельно — на максимальных разумных (см. LTX_MAX_MEGAPIXELS / MINIMAX_MAX_MEGAPIXELS
  в коде) для оценки времени/VRAM на верхней границе.
